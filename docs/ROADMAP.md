# 项目路线图 (Roadmap)

## v0.1：工程骨架与基础驱动
- [x] Makefile（全标准变量兼容：CC、CFLAGS、LDFLAGS、LDLIBS、DESTDIR、PREFIX）
- [x] 27×5 点阵字模表与文本列渲染引擎（可变宽 3–4 列字形）
- [x] PC 终端模拟器（27×5，■/·，n/p 切页，空格息屏）
- [x] 本地系统监控（CPU/内存/温度/网速，仅读取 `/proc` 和 `/sys`）
- [x] 纯本地中国农历转换（1900–2100 年查表法，含闰月支持）
- [x] 纯本地日出日落天文算法（NOAA 纯数学计算）
- [x] TM1628A 双屏位翻转协议与 GPIO cdev/sysfs 双后端硬件驱动

## v0.2：实体按键手势与状态指示
- [x] `button.c`：接入机身 `screen` 实体按键（结合 procd 信号通知）
- [x] 按键手势状态机：短按切页、双击跳回首页、长按待机息屏/唤醒
- [x] 硬件中断式打断休眠（按键响应延迟 < 1ms）
- [x] 独立指示灯后台持续采样与阈值判断（切页状态不滞后）

## v0.3：显示优化、自定义排序与 OpenWrt/LuCI 原生集成
- [x] 彻底去除横向翻滚跑马灯，27 列单屏静态居中防晃眼排版
- [x] 固定时钟冒号，去除高频闪烁
- [x] 监控数据固定列槽位与前导 0 隐藏（网速跳变不移位）
- [x] 网速 EMA 指数移动平均平滑滤波与 Byte/s（K/M/G）换算
- [x] 统一默认显示与预览顺序：时钟 → 下载 → 上传 → 内存 → CPU → 温度 → 日期 → 农历
- [x] 标准化 OpenWrt 源码包命名（`athena-led-c` / `luci-app-athena-led-c`）
- [x] 完整的 LuCI Web 管理界面（HTML5 Canvas 点阵仿真预览、一键自定义上移/下移排序、双组件版本回显）

## 未来规划 (Future Plans)

- [ ] 更多自定义文本与传感器信息扩展接口
